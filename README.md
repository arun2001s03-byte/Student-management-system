# Student Management System

A PHP and MySQL based Student Management System for managing student information.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript

## Features

- Student Registration
- Student Login
- Dashboard
- Student List
- Search Students
- View Student Profile
- Edit Student Details
- Delete Student
- Profile Picture Upload
- Session-based Login
- Logout

## Project Structure

- `login.php` - Student login
- `register.php` - Student registration
- `dashboard.php` - Dashboard
- `student-list.php` - Student list and search
- `profile.php` - View student profile
- `edit-student.php` - Edit student details
- `header.php` - Dashboard header
- `sidebar.php` - Dashboard sidebar
- `logout.php` - Logout
- `check_login.php` - Login session checking
- `db.php` - Database connection

## Database

This project uses MySQL as the database.

Database name:

`arun`

Main table:

`students`

## How to Run

1. Install WAMP Server.
2. Clone or download this repository.
3. Place the project inside:

`C:\wamp64\www\php\`

4. Create the MySQL database and `students` table.
5. Update the database connection in `db.php` if required.
6. Start Apache and MySQL from WAMP.
7. Open the project in your browser.
